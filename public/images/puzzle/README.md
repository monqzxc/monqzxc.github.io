# Puzzle artwork sources

The eight PNGs are unmodified downloads from the [PokeAPI sprites repository](https://github.com/PokeAPI/sprites), using its standard [official-artwork folder](https://github.com/PokeAPI/sprites/tree/master/sprites/pokemon/other/official-artwork). These are the regular artwork variants, not the custom shiny variants. Retrieved 2026-09-26. Each image is 475 x 475 pixels.

Names and National Pokedex numbers were verified against [PokeAPI's Pokemon data](https://github.com/PokeAPI/pokeapi/blob/master/data/v2/csv/pokemon.csv).
